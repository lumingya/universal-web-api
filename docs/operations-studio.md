# 标签页池与请求监控：Operations Studio

延续站点配置已采用的米白 / 橄榄绿视觉体系，保持原全局导航、Logo 与深色模式。本轮不涉及后端接口或用户配置迁移。

## 标签页池

- 状态概览为可点击的筛选卡：全部、空闲、执行中、需要关注（错误 / 关闭 / 未知）。与关键词及路由组筛选组合使用，计数基于当前分组，不修改标签页。
- 桌面双列网页卡、手机单列。域名、状态与当前任务在最上方；模型名称、预设和执行信息直接可见。
- 六类调用地址保留在原生 `details` 中，按需展开、复制。保留原 URL 编码、默认预设、固定标签页与路由组规则。
- 路由组通过横向快捷入口选择；调度、分组和自动刷新在按需打开的侧栏中管理，替代常驻的第二条图标栏。保留宽度调整、组成员编辑、创建 / 删除和保存。
- 标签页模型临时 / 站点 / URL 命名、预设切换、排除 URL、异常保留与任务终止沿用原方法和权限/加载保护。
- 空列表提供接入步骤；加载失败与真正的空池分开表达，配置未加载时不开放写操作。

## 请求监控

- 默认打开**请求记录**，不再先滚过多屏用量图。顶部突出执行数 / 排队数、当前统计样本、样本成功率、成功请求平均耗时。
- 成功平均耗时沿用原计算；P95 来自全部当前样本。样本数与多模态筛选一致，累计服务用量不会冒充当前样本。
- 搜索、成功 / 失败 / 取消筛选、包含多模态开关、分页与惰性详情加载保留。
- 请求详情保持原输入输出、截断内容展开、耗时与完整错误日志；补充初始焦点、Tab 循环、Escape 关闭与返回焦点。
- **用量分析**为独立但保持挂载的视图，保留累计用量、当天小时曲线、每日趋势、模型占比和时间范围。切换视图不丢失历史列表筛选。
- 请求趋势、站点 / 模型排行收进“流量趋势与站点分布”；系统负载仍按需打开。
- 无样本时成功率 / 延迟显示 `—`，零用量不再显示无意义的 50% 比例。

## 代码边界

- `TabPoolTab.js`：新增只读筛选 computed、页面结构及侧栏键盘交互。原业务方法不变；原方法仅调整侧栏宽度计算相关的交互。
- `RequestMonitorTab.js`：新增视图状态、重排现有模板、详情焦点交互。统计、过滤、缓存、详情读取和接口调用保留。
- `operations-studio.css`：仅限定 `.ops-pool` / `.ops-monitor`，使用全站色彩 token，不影响已完成的站点配置页。
- `icons.js`、`index.html`：补充同风格线性图标并更新资源版本。

目标测试共 **61 passed**。真实 Chromium 冒烟测试另覆盖：

- 标签页状态 / 关键词 / URL 成员分组筛选、空结果恢复；展开不写入，字段 DOM 保留。
- 六种调用地址和复制内容；真实预设、分配模式及组成员保存请求体（写 API 模拟）。
- 模型编辑及危险操作取消不写入；侧栏暂停刷新、键盘调整宽度与关闭。
- 请求分页、失败 / 取消 / 多模态 / 关键词筛选，详情请求、错误日志与焦点返回。
- 用量视图、时间范围、排行、趋势和系统负载入口，往返后保留筛选。
- 1280 / 1024 / 768 / 390 / 375px 无页面横向溢出；补充网页卡正文最小宽度及刷新按钮换行断言。
- 真实空状态及错误读取状态；深色、手机和有数据页面截图人工检查。
- 未捕获的 JavaScript 异常为 0，所有用户 `config/*.json` 文件哈希前后相同。

冒烟脚本的数据为**合成回归数据**，仅由浏览器拦截返回，不写入项目配置或生产页面；所有写 API 与剪贴板也被拦截。当前未连接已登录的受控浏览器，因此不声称验证了真实 AI 请求、真实任务终止或第三方网页状态。
