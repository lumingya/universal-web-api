# Gemini / DeepSeek：结构化工作流与 DeepSeek 单预设收敛

> 后续用户要求已覆盖最初的 DeepSeek 三预设方案：目前只保留「主预设」，不读取或切换模型、不包含实验性直发。模型沿用网页当前选择。下文 Gemini 升级仍保持不变。

## 范围与兼容

- 实际配置键为 `gemini.google.com`，现有 `gemini.com` 路由别名保持不变。
- Gemini 的 4 个预设保留名称与默认选择；DeepSeek 删除原专家、快速、实验性预设，统一为默认「主预设」。
- Gemini 只调整 workflow；DeepSeek 主预设以原普通「专家模式」的非工作流配置为基础，保留网络解析器、附件/文件粘贴、媒体提取、提示词填充、站点级配置和发送确认，只移除闲置的模型选择定位器。其他 AI 站点不变。
- 不引入隐藏的运行时模板引用。每套配置仍可独立导出、导入和编辑。DeepSeek 删除多余预设是后续用户的明确要求。
- Gemini 的差异集中到组变量：目标模型匹配式与临时会话开关。DeepSeek 不再含模型状态变量。

## 流程调整

### Gemini

保留原中文界面提示，并将流程组织为三个步骤组：

1. **准备新对话与隐私模式**：只调用原新对话入口一次，去掉重复的 `Ctrl+Shift+O`。私密预设读取临时对话按钮的 `aria-pressed`，已经开启则不重复点击；非隐私预设不进入此分支。私密预设的入口缺失时停止，不再静默忽略。
2. **只在需要时切换模型**：读取现有模型按钮文本，匹配预设模型时跳过菜单动作；不匹配则读取 `aria-expanded`，仅在菜单关闭时展开，再选择原预设模型。展开时等待目标选项可见、选择后等待选项隐藏，替代原固定等待。
3. **发送并读取回复**：保留填写、发送、监听及原发送确认配置，不增加另一种重复发送动作。

没有猜测或变更供应商当前模型名称。原名为 `3.5 flash lite` 的预设，其选择器实际匹配 `3.1 Flash-Lite`，此次保留原定位，不擅自“修正”为未验证的模型。

### DeepSeek（当前方案：仅主预设）

仅保留两个组、四个执行动作（含组一共 6 个节点）：

1. **准备新对话**：调用原可选新对话入口。
2. **发送并读取回复**：填写本次请求 → 回车发送 → 监听并读取回复。

不包含模型选择、模型状态读取、条件判断、固定等待或 PAGE_FETCH。脚本不改变网页当前模型，用户需要时直接在网页上选择。主预设从普通预设继承设置，不继承实验性直发参数。默认预设为「主预设」。旧预设的显式 API 调用名应改为主预设。

当前工作区 `commands.json` 无旧预设引用，也没有 `sites.local.json` 本地默认覆盖。若部署环境的标签页仍绑定旧预设，应重新选择「主预设」。不修改历史请求记录与市场缓存。

## 自动收录过滤

- 原问题：未知域名即使没有 HTML、AI 分析失败，仍将通用 `textarea / submit / div` 回退配置写入站点库。
- 修正：通用回退只返回给当前调用，不放入 `sites`，不写入文件，因而不会出现在目录。
- 搜索首页与账号页可用 `config/site_rules.json` 的 `auto_discovery: false` 精确排除。规则支持 `www` 别名，但不会扩展到所有子域：排除 `google.com` 不影响 `gemini.google.com` 和 `aistudio.google.com`。
- 未知站点必须由分析器明确返回布尔 `is_chat_site: true`，且具有非通用的回复容器和输入定位，两者都要实际匹配被分析的 HTML 快照，才允许自动入库。搜索、登录、普通表单、证据不足的页面不会被默认当作 AI 聊天页。
- 这不是供应商白名单。新的第三方 AI 聊天页仍可识别；用户显式添加或导入的配置仍可使用，不受自动收录策略限制。
- 已误收录的 `www.google.com` 通用预设从本次配置中移除；升级脚本只删除与归档一致的旧条目，不删除后来被用户定制过的 Google 配置。

## 备份与验证

`gemini-deepseek-v2.before.json` 保存升级前两个站点及误收录 Google 条目，可通过站点导入恢复。只想回退一个站点时，请从文件选择对应来源，避免恢复无关条目。

显式升级脚本：`python scripts/upgrade_gemini_deepseek.py`。非启动迁移，可重复执行；处理 Gemini 的 4 个指定预设与 DeepSeek 单预设合并；已有单独的主预设不会被重复重建。

回归：

```sh
python -m pytest -q tests/test_site_workflow_upgrade.py tests/test_site_discovery.py
# 本地服务启动后，检查实际控制台加载与 Google 条目移除（拦截写入）
python tests/browser_upgraded_sites.py
```

覆盖配置差异边界、Gemini 的状态分支、菜单已展开场景、临时会话差异、DeepSeek 仅四个动作且保持网页模型不变、搜索域名过滤、未知回退不入库、正向识别与手动配置兼容；包含合成网页上实际 CSS/XPath 定位、点击、输入及回车测试。

**边界**：未登录真实 Gemini / DeepSeek 验证。网页没有可读的选中标记时，只做一次原点击，不能宣称已验证模型状态；现有中文定位器仍依赖页面实际结构。DeepSeek 不再执行实验性直发。

最新合并前备份：`deepseek-single-preset.before.json`，包含上一版 3 个完整预设；需要回滚时可显式导入。
